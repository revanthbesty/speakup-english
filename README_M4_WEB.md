# SpeakUp Phase 5 — M4 Web/PWA Learner Experience v1.6.0

Connects the MVP learning loop to a responsive Next.js learner UI.

## Routes
- `/` landing
- `/home` learner home
- `/journey` journey/unit
- `/lesson` lesson flow
- `/activity` sentence builder
- `/speaking` speaking state
- `/feedback` feedback/retry state
- `/progress` progress and recommendations

## UX rules
- Home/Journey/Progress are primary navigation.
- Meaningful learning evidence is visually distinguished from completion.
- Speaking exposes microphone/recording states and privacy messaging.
- Feedback is supportive and actionable; never uses "Wrong".
- Responsive mobile layout is included.
- The current slice uses deterministic MVP presentation data while backend API integration is prepared for the next web integration step.
