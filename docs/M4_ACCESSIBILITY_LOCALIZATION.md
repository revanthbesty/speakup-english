# M4 Accessibility + Localization

Implemented a shared cross-cutting foundation for the Web/PWA.

## Accessibility
- Text scale: normal/large/extra large
- Reduced motion
- High contrast
- Keyboard/focus-ready styling
- Screen-reader utility class
- Semantic language/dir attributes
- Persistent learner preferences

## Localization
- Supported locales: English, Hindi, Tamil, Arabic
- Translation-key contract with English fallback
- Locale-aware number/date formatting helpers
- RTL readiness for Arabic
- Persisted locale selection

## Architecture
Accessibility and localization are presentation concerns. They do not modify learning evidence, mastery, XP, proficiency, or entitlements.
