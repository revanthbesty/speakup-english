# English Mint — Approved reference UI/UX rescue, phase 3

Based on the saved project visual reference boards: **EnglishMint UI Sprint 1 Design System Poster**, **EnglishMint UI_UX Modernisation Sprint Plan**, and **English Mint: Complete Learning App UI Poster**.

## Delivered in code
- Speak's primary voice action is now above the fold; the existing permission/typed-response flow is retained and the lengthy Speaking Passport notes are collapsible.
- Mint Clips is visually rebranded with a richer purple-blue immersive captioned player and a larger scene illustration area. The source remains a finite offline frame/story catalogue, **not** a streamed video reel.
- Professional English now has one primary Continue lesson hero and colorful cards for roleplay, interviews, meetings, writing, negotiation and industries; existing pilot modules and saved verified completion records remain intact.
- AI Life has an illustrated-style hero, accessible world/activity alternatives and truthful locally persisted café mission progress. No camera/LLM/family network service is implied.
- Help has an offline topic search and clear accessible option cards; existing navigation callbacks remain.
- Games has a distinct colorful landing with actual supported category entry points; gameplay and Grammar pack selection no longer flood the hub. Existing game rewards remain authoritative and unchanged.

## Important visual-reference limits
- Mascot is drawn with the existing repo's `mint_mark` brand drawable; the exact 3D illustrated character panels in the *concept poster* are not included as working drawable assets in the current repository.
- Existing finite Mint Clips animations and story captions remain; original poster scenes were concept illustrations, not validated/licensed production video assets.
- Original 500/9,500/10,000 question content and reviewed professional catalogs are still not established as imported and approved.
- This is a UI presentation redesign, **not** full feature completion or changed score policy.

## Test matrix
Fresh install: onboarding; five bottom tabs; Home daily action; Games landing -> Grammar pack 1 -> answer and Back -> Games; Clips navigation/captions/offline; Speak mic consent/deny -> text; Professional -> six existing modules; AI Life -> café story and Buddy text; Profile -> Settings -> theme -> Back; Profile -> Progress and Help. Preserve Preferences, achievements, all reward IDs and old history. Test small and large phones, large font, TalkBack, light/dark/night, airplane mode, reduced motion, Android API29 and API35. Automated CI/build success alone does not prove these device validations.

No merge, deploy, payment or production publication.
