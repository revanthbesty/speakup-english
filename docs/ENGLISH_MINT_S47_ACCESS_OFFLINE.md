# English Mint Sprint 47 — Offline, Accessibility and Entitlement Baseline

Core original Professional English text exercises are free and locally authored, independent of network and billing. `MintProfessionalAccessPolicy` tests enforce that core practice and review never require a paid entitlement or connectivity. Optional media cannot be presented as available offline until actual asset availability is verified. The Professional Hub now explicitly discloses these limits.

The implementation inherits the existing MaterialTheme dark/light/night configuration; it does **not** add an independent visual theme or claim full TalkBack approval. Physical device reviews must cover TalkBack labels, text resizing up to 200%, color contrast, tap areas, keyboard, screen readers, offline/airplane mode, storage and system TTS fallback.

Still required: audited paid-entitlement billing product flows (if any), truly offline media caching, resilient downloads, captions for complete assets, signed usability tests, compatibility benchmarks and actual dynamic-type/TalkBack screenshots. No change to billing or subscriptions and no purchase introduced. No merge/deployment.
